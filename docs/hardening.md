# 0.2.1 安全加固

按用户确认的顺序加固。用户明确要求暂时跳过现有桌面会话的自动撤权、可靠的单会话急停；保留这一模式，不把独立会话的控制能力宣称为桌面能力。

## 指令有效期与目标绑定

微信服务 `create_time_ms` 必须是有效毫秒时间戳，指令最多两分钟有效；启动前、项目切换前、明显未来或无时间戳的指令拒绝执行并要求重新发送。电脑与手机应保持自动校时。图片下载后再次校验有效期和原目标会话。有效时间窗口内另保留最多 10000 条接收收据，避免滚出旧 512 条列表后重放；到容量上限拒绝新任务。记录收据仍先于实际执行，崩溃时不能擅自重复执行。

原生 HTTP POST 同样要求 `sentAt` 毫秒时间戳，过期和重启前请求拒绝；更新的 iOS 源码会携带时间及目标聊天。旧版原生客户端需要更新，iOS 编译和真机验证仍未完成。

## 权限与停止

遥控入口拒绝以 Windows 管理员身份运行。独立 app-server 模式默认项目权限，完整访问只用于下一轮、最多十分钟，回合结束自动撤回；到期先禁用新高权限任务，再中断正在执行的回合。不能确认中断时关闭所拥有的 app-server，不声称所有独立外部进程都已停止。

桌面模式没有权限设置或可靠的单聊天中断接口。它沿用 Codex App 中该聊天的权限；微信“停止”仍是自然语言请求，不能保证正在执行的工具马上停止。用户要求先跳过这两项，使用时在电脑确认权限。

电脑可双击 `紧急停用遥控.cmd`，持久写入停用标记，阻止后续微信接收、下载、任务投递与回复发送，原生 HTTP 也拒绝访问。已在途发送或已开始的桌面任务不能回滚。恢复只在电脑运行 `scripts/enable-remote.ps1`，然后重新启动入口。

`紧急停止Codex.cmd` 先停用遥控，再弹出明确确认框。确认后强制结束当前 Windows 用户的所有 Codex.exe 进程树，可能中断未保存的修改，包含其他聊天；它不冒充单会话停止，不自动执行，也未在正在使用的 Codex 上试杀。操作失败会要求任务管理器核对。

## 项目白名单

项目白名单默认关闭，未设置开关的旧配置也视为关闭。微信发送“开启白名单”启用限制，发送“关闭白名单”取消限制；“状态”显示当前开关。开关只接受绑定账号的新鲜消息，立即生效并保存，重启后保留；开关不改变 Codex 桌面的执行权限。关闭时可选择所有本地项目，开启时才按已保存的名单过滤。初始批准名单只包含最初项目，关闭开关不会删除名单。

开启后，切换列表和直接目标连接都检查真实目录路径，拒绝白名单外项目，不能靠另一种路径拼写绕开。若启动时绑定了未批准的桌面项目，微信入口保持运行，但不执行任务、不回传该项目聊天内容；发送“切换项目”即可选回已批准的项目。电脑添加项目：

```powershell
.\scripts\allow-project.ps1 -Project 'D:\要批准的项目'
```

撤销加 `-Remove`；修改后重启入口生效。微信不能批准新项目。撤销不能停止已经开始的任务。

## 回传与图片资料

桌面模式仅自动回传程序登记的手机任务。电脑另外发起的回合不自动发送，`状态`也不取它的最近答复。敏感任务可发送 `不回传`、换行后写任务，执行和电脑记录保留，答复不发微信。来源标记只是用来关联回合，不是另一套身份认证。

所有微信发送内容在分段前过滤常见 API 密钥、Bearer 凭据、密码赋值、私钥块格式；格式过滤无法识别所有私人信息，不能把它当作自动保密保证。不回传模式更适合敏感任务。

图片提示明确将图中文字视为不可信资料，不当作执行指令或扩大权限的授权；这只降低提示误用，真正的执行边界仍由 Codex 权限负责。

## 凭据与图片留存

配对密钥、微信 Bot token、回复 context 用 Windows DPAPI CurrentUser 加密；保留当前用户专用目录 ACL。旧明文在读取时自动迁移，绑定前配置备份的密钥也迁移。加解密失败拒绝启动或发送，不降级明文。DPAPI 不能防止已控制同一 Windows 用户的程序读密钥，也不能替代微信账号安全。

生成的图片最多保留七天、总量最多 200 MiB，启动、每小时和新下载时清理；只处理程序 UUID 文件名的普通图片，拒绝链接目录，不递归删除其他目录或非图片文件。原有图片引用在清理后可能失效，需要重新发送。

电脑运行 `scripts/unbind-wechat.ps1` 可停用入口并移除本机微信凭据和回复状态，保留聊天及图片。本机删除不等于服务端撤销，需另在微信连接设置解除授权。手机没有恢复停用或重新批准项目的能力。

## 验证范围

20 项自动测试覆盖时间与目标错误不执行、收据滚动去重、图片下载期间目标变化、单轮及运行中权限到期、停用标记阻止副作用、白名单及目录链接替换拒绝越界、电脑答复不回传、敏感字段过滤、DPAPI 实际加解密与损坏失败、图片保留期限与空间上限，以及关闭所拥有的 Windows RPC 父进程后其实际子进程停止。Windows PowerShell 5 还实测了加密配置、重复配对显示、白名单增删、停用/恢复和本机解绑。

不通过试杀当前 Codex 验证紧急结束按钮；不声称真实微信/iPhone 或桌面权限控制已验收。首次加载需要关闭旧微信窗口，再双击启动；旧进程不会热更新代码。
